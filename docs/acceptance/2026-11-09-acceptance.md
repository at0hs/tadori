### 0.2 テスト用の手順書（ダミー）

- タイトル：`nginx の設定変更`、タグ：`nginx`・`web`
- 変数：`host`（既定値 `web01.example.test`）、`port`（既定値 `22`）、`admin_password`（秘密）
- 手順：
  1. `設定のバックアップ`：コマンド `ssh -p #{port} #{host} sudo cp /etc/nginx/nginx.conf /etc/nginx/nginx.conf.bak`
  2. `設定の変更`：コマンド `echo #{admin_password} | sudo -S vi /etc/nginx/nginx.conf`、**エビデンス必須**
  3. `構文チェック`：コマンド `ssh #{host} sudo nginx -t`、確認方法 `syntax is ok と出る`
- 切り戻し：1. `バックアップから戻す`：コマンド `ssh #{host} sudo cp /etc/nginx/nginx.conf.bak /etc/nginx/nginx.conf`
